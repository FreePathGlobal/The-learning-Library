# Open Source Learning Library

An open-source collection of metalearning packages for a wide range of topics, skills, and hobbies.

Inspired by the principles in *Ultralearning*, this project provides structured, downloadable learning packages that help people acquire skills more effectively. Each package gathers useful knowledge, common pitfalls, free resources, practice drills, training methods, and printable materials in one place.

## What You Get in a Package

Every package typically includes:

- Core useful information and key facts worth knowing
- Common problems and how to fix them
- Curated sources, links, and preferably free courses
- Printables (worksheets, flashcards, checklists, etc.)
- Practice drills and exercises
- Different training method options
- Material lists organized by learning stage

## Project Goals

- Make high-quality, practical learning roadmaps freely available
- Cover a broad range of skills, topics, and hobbies
- Keep everything modular and easy to contribute to
- Encourage continuous improvement through community review

## Contributing

We welcome contributions! To keep packages consistent and useful, please follow the simple blueprint below when creating or updating a package.

### Package Blueprint

Use this structure for every new package (create a folder named after the skill/topic):

skill-or-topic-name/
├── README.md                 # Overview of the skill + how to use the package
├── 01-overview.md            # What the skill is, why learn it, expected outcomes
├── 02-key-facts.md           # Useful information and important facts
├── 03-common-problems.md     # Frequent issues + solutions
├── 04-resources.md           # Sources, links, free courses, books, videos
├── 05-printables/            # Worksheets, flashcards, templates (PDF/Markdown)
├── 06-drills.md              # Practice drills and exercises
├── 07-training-methods.md    # Different approaches and progressions
└── 08-materials.md           # Material lists by stage (beginner → advanced)

**Guidelines:**
- Prefer free or openly accessible resources whenever possible
- Keep language clear and actionable
- Cite sources
- Focus on practical, evidence-based metalearning techniques
- Packages should be self-contained and ready to download/use

### How to Contribute

1. Fork the repository
2. Create a new branch (`git checkout -b add-skill-name`)
3. Add your package following the blueprint
4. Submit a pull request

Once reviewed and approved, packages will be added to the main library (and eventually the project website).

## Status

This project is in early development. The structure and contribution process are still being refined.
